# История Земли — пиксельный фильм

Интерактивный фильм-симуляция в пиксель-арте: от столкновения протоземли с Тейей и рождения Луны
до 2026 года, а дальше — явно помеченный сценарий-прогноз до 5000 года. 37 глав, ~13 минут на ×1.

**Смотреть:** https://earth-history-bice.vercel.app

```bash
npm install
npm run dev        # http://127.0.0.1:5317
```

## Управление

| | |
|---|---|
| Пробел / клик по кадру | пауза |
| ← / → | предыдущая / следующая глава |
| ↑ / ↓, `+` / `−` | скорость ×0,05 … ×32 |
| Таймлайн внизу | переход к любой эпохе (наведение показывает главу и дату) |
| Перетаскивание мышью, колесо | вращать и приближать планету (на паузе остаётся, при воспроизведении плавно возвращается), двойной клик — сброс |
| C (или ≡) | список всех глав с переходом |
| M | звук (процедурный эмбиент, по умолчанию выключен) |
| S | сохранить текущий кадр в PNG (×4, пиксели без размытия) |
| H | скрыть интерфейс, F — полный экран |

## Как устроено

- Всё рендерится в низком разрешении (~480×270) и масштабируется целым множителем в *физических*
  пикселях экрана без сглаживания — каждый пиксель арта остаётся ровным квадратом.
- **Планета** (`src/planet`) — WebGL-шейдер: полосатое освещение с упорядоченным дизерингом,
  магматический океан, древние процедурные континенты, тектонические плиты (контуры Natural Earth,
  повёрнутые по ключевым эпохам — Пангея собрана подгонкой сопряжённых берегов), лёд, уровень моря,
  облака с циклонами, атмосфера, огни городов по регионам, удары, траппы.
- **События** (`src/planet/events.ts`) — частицы диска обломков после удара Тейи и сборка Луны,
  метеориты, астероид Чикшулуб и выбросы, спутники, траектория «Аполлона», интернет-дуги, расселение людей.
- **Диорамы** (`src/dio`) — 21 сцена на поверхности, нарисованная программно на CPU прямо в пиксельный буфер
  (параллакс, отражения в воде, частицы, процедурные растения и техника, спрайты существ). Каждая сцена
  показывается только в своё время: тираннозавр — в последние миллионы лет мела, паровоз — после 1825 года.
- **Карта на глобусе** (`src/hud/geo.ts`) — подписи городов с историческими названиями (Ханбалык → Пекин,
  Петроград → Ленинград…) и маршруты Колумба и Магеллана.
- **Сценарий** (`src/story`) — главы с датами и субтитрами, состояние планеты как чистая функция года,
  живые счётчики населения и CO₂. Никакого `Math.random`: любой момент фильма одинаков при каждом запуске.

## Отладка

В консоли браузера доступен `window.__earth`:

```js
__earth.at('chicxulub', 0.4)   // глава (id или номер), прогресс 0..1 — пауза и отрисовка кадра
__earth.force(480, 270)        // фиксированное внутреннее разрешение
await __earth.snap('name', 3)  // сохранить кадр ×3 в .snaps/name.png (dev-сервер)
__earth.map(250)               // плоская карта палеогеографии на 250 млн лет назад
__earth.chapters()             // список глав
```

`npm run assets` пересобирает карту плит и копирует текстуры (результат уже лежит в `public/tex`).

## Данные

- Текстуры Земли — NASA Blue Marble / Black Marble (общественное достояние), из пакета `three-globe`.
- Контуры стран — Natural Earth 1:50m (общественное достояние), пакет `world-atlas`.
- Шрифт — Press Start 2P (SIL OFL).
